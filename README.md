# Networking Portfolio

This portfolio documents practical networking labs that I build
while developing my knowledge of computer networking.

My current studies include Cisco Networking Academy's
Networking Basics course.

Rather than reproducing course exercises, the projects in this
repository are used to demonstrate my understanding through
independently built labs, testing, and troubleshooting.

## Technologies

- Cisco Packet Tracer
- IPv4
- Ethernet
- ICMP
- TCP/IP fundamentals

Projects will be added as I progress through my networking studies.
